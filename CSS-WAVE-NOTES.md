# NOVI unified CSS/SVG ribbons v4

All six section ribbons use identical inline SVG vector paths and a single CSS component. There are no ribbon image files. The panel colors are CSS variables for navy/green/pink. Text is live HTML.

The waves are SVG paths (not bitmap images), styled by CSS. This avoids distortion and allows consistent scaling across widths. No global site decorations besides the six ribbons were intentionally changed.
