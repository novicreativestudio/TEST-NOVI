# NOVI 3 Levels & Ongoing Care

- Story Order v1 を基礎に、既存の `#choose-foundation` と `#next-options` セグメントを統合。
- Level 1 Start / Level 2 Establish / Level 3 Expand を、サービス対象と範囲が直感的にわかる3カードとして制作。
- すべてのレベルでマーケティング視点と品質チェックを共通に据える。
- Optional Ongoing Care（$79+ /month）を同じセグメント内に配置。軽微な修正回数無制限／月次サマリー／改善提案。具体的なスコープ規約は正式な契約前に要確定。
- 「WHEN YOU’RE READY FOR MORE」を小さい追補として統合。別の大きなリボンは増やさない。
- 料金の未確定項目は表示せず、Page Speed・SEO・集客成果の保証も記載しない。
- WordPressや他社サイトの直接改修は対象としない。
- 他のセグメント・リボン・アニメーションの編集なし。
